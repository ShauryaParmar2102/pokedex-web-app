# ⚡ Pokédex Web App

A simple Pokédex web application built using HTML, CSS, and JavaScript.

The application retrieves Pokémon information from the PokéAPI and allows users to browse and search for Pokémon and view information about them.

## ✨ Features

- 🔢 Displays 300 Pokémon
- 🔍 Search for Pokémon by name
- 👆 Click a Pokémon to view its information
- 🖼️ Displays Pokémon images
- 🔥 Displays Pokémon types
- 📊 Displays Pokémon stats
- 📖 Displays Pokémon descriptions
- 🎨 Different colours for different Pokémon types
- 📜 Scrollable Pokémon list

## 🛠️ Technologies Used

- 🌐 HTML
- 🎨 CSS
- ⚙️ JavaScript
- 🔌 PokéAPI

https://pokeapi.co/

## 🚀 How to Run

1. 📥 Download or clone the repository.
2. 📁 Open the project folder.
3. 🌐 Open `index.html` in a browser.
4. 👆 Select a Pokémon from the list to view its information.
